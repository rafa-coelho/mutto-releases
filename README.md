# Mutto: instaladores

Este repositório guarda só os instaladores do [Mutto](https://www.mutto.app), o app de mute para Windows 11. Cada release tem os setups x64 e ARM64, o arquivo de versão e o changelog.

Para instalar, use o site, que escolhe a versão certa para o seu PC:

```powershell
irm https://www.mutto.app/mutto/install.ps1 | iex
```

As versões marcadas como pré-lançamento são do beta fechado.
